# 纺织服饰（801130.SI）周期定位档案（TIER B）

- 研究日期锚：2026-07-18；行情与估值截至 2026-07-17 收盘；财务口径：2026Q1 一季报、2025 年报、2026H1 高频数据
- 母公司扫描既有结论（直接沿用，截至 2026-07-17 收盘）：YTD -14.2%、r20 -5.3%、r60 -15.1%、r250 -8.9%、区间位置 43.6%、距年内高点回撤 -20.5%；PE 23.03 / PB 1.61；2026Q1 营收 +6.1%、毛利率 25.59%（同比 -0.13pt）、2025 年报净利 +20.77%（低基数）
- 证据分级：T1 = 公司披露 / 官方统计；T2 = 交叉验证媒体 / 行情终端；T3 = 券商转述
- 申万行业聚合查询在 Gildata 返回空、Wind 持续 429 限流，行业层数据以母公司扫描结果为准（见 §7）

## §0 大白话三行

1. **现在什么情况**：国内人买衣服的钱在慢慢变多——上半年服装类零售额比去年多 6.7%，比全国消费大盘（+1.3%）好不少；但衣服卖到国外还是难，上半年出口按人民币算还降了 2.2%。行业内部冷热不均：种棉纺纱的上游因为棉花、羊毛涨价在赚钱，给国外品牌做代工的还在挨冻，开店卖自己牌子的在中间慢慢回暖。
2. **像历史上哪段**：像 2018 年底到 2019 年初——那次也是美国抡关税大棒、国内消费疲软，板块先跌透，后来靠关税缓和加消费回稳才缓过来。两个重要差别：这回龙头企业分红高（龙头股息率约 7%，相当于股价底下有个软垫），而且大厂早把产能搬去了越南、柬埔寨，关税打在身上没上次那么疼。
3. **接下来盯什么**：盯三样东西——每月中旬公布的服装零售额能不能守住增长（别掉到 0 附近）、出口能不能连续 3 个月转正、8 月底中报里行业的"赚钱厚薄"（毛利率，就是卖货收入扣掉成本后剩下的比例）能不能止跌。

## 1. 变量读数表

**框架**：纺服周期的因果链为 `内需（服装社零 / 渠道库存折扣）+ 外需（出口订单 / 关税）→ 量价 → 中游毛利率（受棉 / 毛 / 汇率成本夹击）→ 报表（营收 / 净利）→ 股价与估值`。

其中**服装社零与出口是 forcing variable（驱动变量）**；板块毛利率、净利是滞后确认族；股价 YTD 与回撤只是症状。按判定纪律：forcing variable 转正 + ≥1 个独立确认族，才允许上调至 early_recovery；单族证据一律标"暂定"。

本行业特殊性在于"一指数、三周期"：品牌服饰由内需消费驱动、纺织制造由出口订单与关税驱动、上游纱线由棉 / 毛价格驱动——三条链的 forcing variable 各不相同，因此下表与 §2 判定均按子链分列。

## 2. 阶段判定与证据

**判定：bottom_observation → early_recovery 过渡边缘（暂定，弱；置信度中低 0.4–0.55）**。方向上与母公司扫描"early_recovery 暂定（弱）"一致，但按子链拆分后更精确——三条链处于三个不同阶段：

- **品牌服饰（内需链）：弱复苏雏形，early_recovery 暂定（单链层面）**。Forcing variable（服装社零）连续 6 个月正增长、H1 +6.7% 大幅跑赢总社零 +1.3%（T1，国家统计局，2026-07-15）；确认族：海澜之家 2026Q1 营收 +7.66%、主品牌收入 +11.17%、2025Q4 单季净利 +21.0%（T1，公司披露，2026-04-29 / 03-27）。两族俱备但质量打折：社零含低基数、6 月单月减速至 +3.9%；海澜毛利率同比 -1.30pt、净利仅 +1.51%——"卖得动"已现、"赚得多"未现。
- **上游纱线 / 涨价链：业绩已兑现，更像 early_recovery 进行中**。百隆东方 Q1 净利 +39.83%、H1 预告 +30%~60%（T1，2026-07-07 公告）；华孚时尚 Q1 净利 +180.98%（低基数）；新澳股份 Q2 羊毛纱线接单出货双位数增长（T3，山证周报，2026-07-14）。注意：驱动力是棉 / 毛涨价 + 越南产能红利，而非终端需求扩张，持续性取决于原料价格与订单排期。
- **中游出口代工：仍处 profit_pressure（承压）**。华利集团 Q1 营收 -19.4% / 净利 -49.6%（T1，2026Q1）；H1 全国出口 -2.2%（T1）；关税仅为"暂停 + 展期"式缓和。6 月出口单月 +2.1%、越南纺服出口增速转正（T3，2026-07-14）是边际改善信号，但单月读数不构成趋势确认。

**冲突证据并列**（为何不升级 early_recovery）：

1. 毛利率未回升：2026Q1 板块毛利率 25.59%、同比 -0.13pt——营收转正但盈利质量没改善（T2）；
2. 2025 年净利 +20.77% 是低基数读数：2026 年中报起基数抬高，增速大概率回落；
3. 出口链未稳：H1 出口仍负、代工龙头华利 Q1 净利近腰斩，与"复苏"表述直接冲突；
4. 中报预喜率前列行业无纺服（截至 2026-07-15，T2）。

**证伪条件（任一触发即退回 profit_pressure / clearing）**：

1. 服装社零连续 2 个月 ≤0，或连续 2 个月弱于总社零增速；
2. 纺织服装出口单月同比重回 -5% 以下，或中美关税缓和窗口破裂再升级；
3. 2026 中报板块毛利率同比降幅扩大至 -1pt 以上且净利增速转负。

**小结（一句话）**：这更像"内需品牌链的弱复苏 + 上游涨价链的业绩兑现 + 中游代工链的关税磨底"三态叠加，而不是整个行业的统一复苏——指数 +6.1% 的营收读数掩盖了内部接近腰斩与接近 +40% 并存的极端分化，因此只给"暂定"，等待毛利率与中报把这三个故事收敛成一个。

**与 7/13–17 市场大调整的关系（症状层校准）**：YTD -14.2% 中，近 60 日贡献 -15.1%，即年内跌幅几乎全部来自 5 月中旬以来的持续走弱（关税反复 + 消费数据波动），而非 7/13–17 单日冲击；调整当周资金高低切换流向煤炭、食品饮料、银行等防御板块（中证金牛座周复盘，2026-07-18，T2），纺服虽具备低估值（PB 31 行业第 11 低）与高股息特征，但未进入当周防御抱团名单——侧面说明其"内需弱复苏"叙事尚未获得资金共识，与本文"暂定、置信度中低"的判定互相印证。

## 3. 距复苏确认还差什么（缺失确认族清单）

从 bottom_observation 升级到 early_recovery，按纪律需 forcing variable + ≥1 独立确认族。当前 forcing variable 已现方向（社零正增长、出口单月转正），缺的是以下确认族证据：

1. **毛利率确认族**：需 2026 中报板块毛利率同比止跌（≥0pt）——当前 -0.13pt，未出现；
2. **出口订单确认族**：需出口连续 3 个月单月正增长 + 美国服装进口商补库 / 越南柬埔寨订单协同数据——当前仅 6 月单月转正；
3. **渠道健康确认族**：品牌服饰库存周转、终端折扣率、同店增长——本轮未系统取得（见 §7），无法验证"卖得好"是否以打折为代价；
4. **板块中报整体确认**：需 8 月板块中报净利增速在低基数消退后仍为正，且预喜个股从上游纱线扩展到品牌与中游制造；
5. **资金确认族**：公募 / 北向纺服持仓回升数据未取得；"7 月风格切换流入"目前仅有券商定性描述（T3）。

## 4. 一个历史参照点：2018–2019 中美贸易摩擦冲击与修复

期间约 2018-03（美方公布 301 关税清单）至 2019-12（第一阶段经贸协议签署）。

**机制链（与本轮高度同型）**：终端零售走弱 + 关税威胁 → 2018 年 SW 纺服板块随大盘走跌、出口先"抢跑"后回落、棉价上行挤压中游（智研咨询《2018 年纺织服装行业重仓持股情况回顾》，2019-03-05，定性描述）→ 2018 年报业绩见底 → 2019Q1 起行业"由筑底转向复苏"（券商《纺织服装行业 2018 年报及 2019 年一季报回顾》标题原话：大众服饰筑底企稳、中高端女装 19Q1 复苏趋势确立，2019-05-06）。

**当时可知 vs 事后**：当时可知的是关税清单、零售逐月走弱、棉价上行；当时不可知的是谈判在 2019 年 5 月、8 月两度破裂再升级、以及最终协议文本——2019 年的修复中途被反复打断。

**对本轮的三点映射**：①同样处于"外需关税 + 内需走弱后的弱修复"，当前位置更像 2018 末–2019 初"筑底转向复苏"的前夜；②不同处——本轮内需有提振消费政策定调（《求是》2026-06-18 刊文）、龙头高股息（海澜 TTM 股息率约 7%）提供估值垫、制造端已完成越南 / 柬埔寨产能布局（百隆越南工厂盈利提升、伟星越南基地、申洲东南亚产能），关税敏感度低于 2018；③教训——单月出口转正（2018 年的抢出口、2026-06 的 +2.1%）不等于趋势反转，缓和窗口的持续性才是分水岭。（注：2018 年板块精确涨跌幅本次未取得行情序列验证，仅引用定性结论，见 §7。）
